# javascript-calculator-precourse

## 📈 구현할 기능 목록

- **입력**
  - [x] 계산을 위한 문자열 입력받기
    - `Console.readLineAsync`를 사용해 구현했습니다.

- **출력**
  - [x] 계산 결과 출력하기
    - `Console.print`를 사용해 구현했습니다.
  - [x] 사용자가 잘못된 값을 입력할 경우 에러 메세지 출력하기
    - `[ERROR]`로 시작하는 에러 메시지를 출력합니다.

- **기능**
  - [x] 커스텀 구분자가 있는지 확인하는 기능 구현하기
    - `hasCustomDelimiterHeader` 함수로 "//" 시작 여부를 확인합니다.
  - [x] 커스텀 구분자로 문자열을 분리하는 기능 구현하기
    - `extractCustomDelimiter` 함수로 "//<문자>\n" 형식에서 구분자를 추출합니다.
  - [x] 기본 구분자로 문자열을 분리하는 기능 구현하기
    - 쉼표(,)와 콜론(:)을 기본 구분자로 사용합니다.
  - [x] 빈 문자열을 입력하면 0을 반환하는 기능 구현하기
    - 전체 입력이 빈 경우와 커스텀 구분자 뒤가 빈 경우 모두 `결과 : 0`을 반환합니다.
  - [x] 분리된 문자열에서 숫자를 추출하는 기능 구현하기
    - `Number()` 함수를 사용해 정수와 소수 모두 지원합니다.
  - [x] 숫자들의 합을 계산하는 기능 구현하기
    - `reduce` 함수를 사용해 합계를 계산합니다.
  - [x] 이모지를 포함한 유니코드 문자 구분자 지원
    - `spread operator`를 사용해 정확한 문자 길이를 계산합니다.
  - [x] 계산기에 사용되는 항목(숫자, 소수점) 구분자 금지
    - 정규식 `/[\d.]/`을 사용해 금지된 구분자를 차단합니다.

## 🎯 예외 예상 상황 목록

- **입력받은 문자열 부분**
  - [x] 입력받은 문자열이 없는 경우
    - 0을 반환 `(결과 : 0)`
  - [x] 0 이하의 숫자를 입력했을 경우
    - 에러를 반환 `[ERROR] 양수만 입력할 수 있습니다.`
  - [x] 숫자가 아닌 값을 입력했을 경우
    - 에러를 반환 `[ERROR] 숫자가 아닌 값을 입력하시면 안됩니다.`
  - [x] 구분자를 기준으로 값이 비어 있는 경우
    - 에러를 반환 `[ERROR] 구분자를 기준으로 값이 비어 있습니다.`
  - [x] 공백만 있는 값을 입력한 경우
    - 에러를 반환 `[ERROR] 공백만 있는 값은 입력할 수 없습니다.`

- **커스텀 구분자 처리 부분**
  - [x] 커스텀 구분자 형식이 잘못된 경우
    - 에러를 반환 `[ERROR] 커스텀 구분자 형식이 올바르지 않습니다.`
  - [x] 커스텀 구분자를 입력하지 않았을 경우
    - 에러를 반환 `[ERROR] 커스텀 구분자가 비어 있습니다.`
  - [x] 커스텀 구분자로 여러 문자가 입력된 경우
    - 에러를 반환 `[ERROR] 커스텀 구분자는 한 글자만 입력할 수 있습니다.`
  - [x] 커스텀 구분자로 숫자나 소수점을 입력한 경우
    - 에러를 반환 `[ERROR] 커스텀 구분자로 계산기에 사용되는 항목(숫자, 소수점)은 입력할 수 없습니다.`
  - [x] 커스텀 구분자 뒤에 값이 없는 경우
    - 0을 반환 `(결과 : 0)` - 빈 문자열 입력과 동일하게 처리했습니다.
